# HWEE — Hello World Enterprise Edition 13.0.0

Платформа промышленного масштаба для критически важной доставки одной строки
в стандартный вывод.

```console
$ make run
Hello, World!
```

(≈ 20–40 секунд, ~60 000 вызовов самописного SHA-256, ~2.5 млн NAND-вентилей,
один view change в PBFT, 14 блоков в блокчейне, 14 системных вызовов `write`.)

## Как это работает

Строки нет в коде рантайма — это проверяется тестом
`tests/test_end_to_end.py::test_runtime_contains_no_greeting_literal`.
Она восстанавливается заново при каждом запуске:

| # | Стадия | Что происходит |
|---|--------|----------------|
| 1 | FIPS self-test | Самописные SHA-256 (константы выводятся из кубических корней простых чисел) и CRC-32 сверяются с `hashlib`/`zlib` |
| 2 | Provisioning | DI-контейнер с autowiring; оракулы находятся рефлексивным сканированием пакета через `GlyphOracleFactoryProvider → AbstractGlyphOracleFactory` |
| 3 | Divination | Пять независимых оракулов (N-version programming) вычисляют коды символов: |
|   | • polynomial | значения интерполяционного многочлена Лагранжа 12-й степени, вычисленные на симулированных NAND-вентилях с тройным модульным резервированием (Horner запрещён, ADR-0004) |
|   | • hash_inversion | brute-force обращение солёного растянутого SHA-256 в пуле процессов, порядок перебора — полнопериодный LCG |
|   | • brainfuck | Brainfuck-программа исполняется интерпретатором Brainfuck, написанным на ассемблере HWASM, собранным в объектный файл HWVM и запущенным на стековой VM |
|   | • lambda | нормальная редукция λ-термов с индексами де Брёйна до чисел Чёрча |
|   | • chaos_monkey | византийский оракул, который врёт, чтобы постоянно доказывать отказоустойчивость |
| 4 | PBFT | Practical Byzantine Fault Tolerance по каждому символу и по длине; хаос-мартышка — primary в view 0, поэтому каждый запуск начинается со смены вида |
| 5 | Neural attestation | Студенческая MLP на самописном scalar autograd + Adam обучается на результате консенсуса и обязана его воспроизвести |
| 6 | Ledger | Каждый символ — отдельный блок с Merkle root и proof-of-work (double SHA-256) |
| 7 | Reconstruction | Валидация цепочки и извлечение кодов |
| 8 | Optical | Растеризация шрифтом 5×7, «пыль сканера», OCR по расстоянию Хэмминга |
| 9 | Transport | собственный UTF-8 → Хаффман → Base64 → Hamming(7,4) → шумный канал → исправление ошибок → CRC-32 |
| 10 | Emission | Retry с экспоненциальным backoff + circuit breaker, один `os.write` на байт; перевод строки — `UnixLineTerminatorStrategy` |

Все сообщения между компонентами консенсуса проходят через шину,
сериализуются в JSON, оборачиваются CRC-32 и валидируются самописным JSON Schema.
Все артефакты в `src/hwee/resources` проверяются по манифесту SHA-256.

## Использование

```console
$ make verbose                       # рассказ о путешествии в stderr
$ python -m hwee --telemetry         # отчёт с трейсами и метриками
$ HWEE_DIFFICULTY=14 make run        # для тех, у кого слишком быстрый компьютер
$ make test
```

Зависимостей нет: всё, включая криптографию, big-int арифметику, нейросети и
парсер конфигурации, написано с нуля (ADR-0001).

## Перегенерация артефактов

```console
$ make artifacts GREETING="Hello, World!"
```

См. `docs/architecture.md` и `docs/adr/`.
